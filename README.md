# A cohort project of Developing a Secure Student WIL Hours Tracker
 
## Project Overview
 
The Secure Student WIL Hours Tracker is a cloud-based solution designed to assist students in recording, monitoring and verifying the mandatory 320 Workplace Integrated Learning (WIL) hours required by CTU.
 
The system allows students to clock in and out, upload supporting evidence, monitor progress, and obtain mentor approval through a secure workflow.
