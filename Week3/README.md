## Week 3 Objective

The objective of Week 3 was to move the project from the requirements phase into the design phase.

During this week, the team focused on designing how the Secure Student WIL Hours Tracker will function, where it will be hosted and how it will be secured before development begins.

The project design was aligned with Software Development, Cloud Computing and Cybersecurity requirements.

---

## Deliverables

### Design Pack

The Design Pack defines:

- Project Overview
- Solution Architecture
- Cloud Architecture
- Security Architecture
- Security Requirements
- OWASP ASVS Security Controls
- NIST Risk Management Framework (RMF) Alignment
- Team Responsibilities
